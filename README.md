# Taci PRO: instaladores

Este repositório guarda só os instaladores do Taci PRO. Ele não tem código.

Para baixar, use a página de download: https://tacipro.devoutbox.com/download

Cada versão é uma Release, com três arquivos:

- `TaciPRO-windows.exe`: Windows
- `TaciPRO-mac-apple.dmg`: Mac com chip Apple (M1 em diante)
- `TaciPRO-mac-intel.dmg`: Mac com processador Intel

Para saber qual é o seu Mac: menu Apple, **Sobre este Mac**. Se aparecer "Chip Apple M…", use o de chip Apple; se aparecer "Processador Intel", use o de Intel.

Ajuda e suporte: https://tacipro.devoutbox.com/ajuda

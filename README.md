# Taci PRO: instaladores

Este repositório guarda só os instaladores do Taci PRO para Mac e Windows. Ele não tem código.

Para baixar, use a página de download: https://tacipro.devoutbox.com/download

Cada versão é uma Release, com dois arquivos:

- `TaciPRO-mac.dmg`: Mac
- `TaciPRO-windows.exe`: Windows

Ajuda e suporte: https://tacipro.devoutbox.com/ajuda
